.issue-badge Small label that identifies what the story is about. Without any special positioning, it displays with the normal document flow after the header element's introductory eyebrow and heading. position: absolute - it lets the item sit at the top right corner, without obscuring the header elements or pushing any other content inside down. .feature-header, and it positions within the limits of this container (which is "relative"). Below 400px, the badge will stop its absolute position and return to the natural document flow, under the main heading. Testing at viewports of 320/768/1280px, 200% zoom, larger font and with CSS disabled.
.story-guide A small navigation menu that will jump to each story section In the normal document flow, it sits at the very top of the main content. position: sticky, allows it to remain visible as we scroll down. It sticks within the 'main' element container, and will stop scrolling when 'main' ends. Smaller viewports under 52rem, no special CSS techniques (position: sticky). Testing at viewports of 320/768/1280px, 200% zoom, larger font and with CSS disabled. Clicking and keyboard-only navigation.
.feature-figure and its image Provides a visual that supports the story, with a caption and image source credit. It's all contained together. Regular document flow, positioned inside the section element, right below the h2 element. The border groups the image with the caption so we can see that it belongs to the image, the radius gives it a stylize smoother edge, and the image element is stylized with clip-path to give it a shape. The element has position: relative, so it becomes a contaner block for child elements (such as absolute, but it's not being used right now). The figure container doesn't create any stacking, but the image element clip-path does. Without any of these stylings, the caption and image remain grouped, and the image displays with the normal rectangular/squre shape. Clip-path disabled. Testing at viewports of 320/768/1280px, 200% zoom, larger font and with CSS disabled.
.pull-quote It is a larger quotation that adds to the main story. It adds a human voice. It sits inside the section element, right below the figure element. Position: relative keeps it at a normal content flow, with -4rem shifting it to the side. It is layered by this property and by z-index, creating a stacking context. position:relative and z-index creates a stacking context, which layers it above the surrounding content. Sits below the figure/image, like a normal block of text or paragraph. Testing at viewports of 320/768/1280px, 200% zoom, larger font and with CSS disabled.
.shape-portrait (image) It provides a visual, that goes alongside the story. It's styling provide a unique shape for the text that wraps around it. The image displays normally right after h2, in an orderly fashion, without the radius shape surrounding it. float, shape-outside: circle(50%), and shape-margin are used. The stage list wraps curved and border-radius: 50% makes the image round. The image is inside the section element, and that section element is inside the article element. Portrait will display normally without the circle margin, so the content will flow normally instead of wrapping around the image. Shape-outside disabled. Testing at viewports of 320/768/1280px, 200% zoom, larger font and with CSS disabled.
